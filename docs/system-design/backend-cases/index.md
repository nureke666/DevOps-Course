# 5. Бэкенд-задачи

Классические задачи system design, которые дают на бэкенд-собесах. Каждая решается по одной
схеме — так легче сравнивать решения и запоминать приёмы:

```text:no-line-numbers
 1. требования      функциональные, нефункциональные, что вне рамок
 2. оценки          RPS, объём, трафик, память под кеш
 3. API             эндпоинты, идемпотентность, лимиты
 4. модель данных   таблицы/ключи, выбор хранилища
 5. схема           путь чтения и путь записи
 6. глубже          2–3 ключевых решения с вариантами
 7. узкие места     что ломается первым при росте ×10
 8. ⚙️ эксплуатация  развёртывание · масштабирование · наблюдаемость · отказы ·
                    данные и DR · безопасность · стоимость
 9. trade-offs      что выбрали и от чего отказались
10. что спросят     продолжения от интервьюера
```
